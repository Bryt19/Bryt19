# 🚀 Featured Projects

## 🔐 TrustLock

### Don't send money to a person. Send it to code.

**TrustLock** is an Ethereum-based escrow platform designed to make peer-to-peer transactions safer by locking funds in smart contracts until agreed conditions are fulfilled.

### Three products. One escrow primitive.

| Product                  | Purpose                                          |
| ------------------------ | ------------------------------------------------ |
| 🏠 **SafeRent**          | Protect rental deposits and agreements           |
| 📦 **Verified Delivery** | Release payment when delivery conditions are met |
| 💼 **Freelance Escrow**  | Protect milestone-based freelance payments       |

**Stack**

`React` `TypeScript` `Solidity` `Ethereum` `Ethers.js` `MetaMask` `Sepolia`
